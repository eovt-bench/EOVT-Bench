# Resources and public results

Git contains code, compressed task definitions, configuration, fixed identity
metadata and input episode examples. Baseline aggregate values and confidence
intervals are archived in `docs/HISTORICAL_REFERENCE_RESULTS.md`. No baseline
per-episode results, result-file inventory or result archive is distributed.

## Simulation assets

Follow [external acquisition instructions](THIRD_PARTY_RESOURCES.md)
([中文](THIRD_PARTY_RESOURCES.zh-CN.md)).
`assets/resource_policy.json` lists sources and destinations.
`assets/manifest.json` pins compatible files; it is not a license grant.

```bash
python scripts/check_resources.py --group metadata
python scripts/check_resources.py --json
python evaluation/validate_package.py
```

A fresh clone lacks simulation assets. All benchmark scenes were constructed
by the benchmark author and are available as a standalone, checksum-pinned
resource archive:

```bash
python scripts/download_resources.py --kind scenes
```
Humanoid acquisition is documented in the resource guide.

An already lawfully held matching complete resource archive can be checked
and installed locally:

```bash
python scripts/download_resources.py --kind assets --archive /path/to/existing/assets.tar.gz
```

This compatibility path verifies hashes, safe paths and conflicting files.
It does not download mixed resource packs or grant redistribution permission.

## Evaluate your own runs

```bash
python evaluation/aggregate_results.py /path/to/your/results --task stt --bootstrap 2000
```

The evaluator reads results generated by the user. The README tables do not
contain enough information to reproduce per-event statistics on their own.

## First-person qualitative videos

A separate qualitative Release contains twelve OmTrackVLA first-person videos
with per-case evidence. See [the case index](../qualitative/omtrack_first_person/README.md).
These selected cases are separate from baseline results and do not contain
simulation meshes or pretrained weights.
